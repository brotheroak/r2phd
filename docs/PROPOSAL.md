# IntentSpec — .EXE-THON 기획서

**한 줄 소개** — 애매한 말을 고르기 쉬운 선택지로 나누고, 뜻이 맞은 뒤에야 AI가 실행하게 하는 소통 에이전트.

GitHub: [brotheroak/r2phd](https://github.com/brotheroak/r2phd) · 데모: `npm run dev` → http://127.0.0.1:3847

## 1. 문제 정의

자연어로 적은 요청과 분석 의도가 AI 실행·SQL 집계로 넘어가며 깨진다. 사람이 쓴 말에는 용어·기준·제약·식별자가 비어 있고, AI는 그 빈칸을 제멋대로 채운다.

- **누가** — LLM에게 일을 시키는 실무자, 그리고 그 결과를 리뷰하는 팀장·동료
- **언제** — AI가 "완료"라고 하거나 SQL이 "정상 실행"된 직후
- **얼마나** — 분석 1건마다 용어·날짜·식별자를 사람이 다시 대조하는 수십 분. 놓치면 틀린 숫자가 회의 자료·신고서에 그대로 고정된다

대표적인 함정:

1. "최근 불량률"의 **최근**을 시험일이 아니라 적재일로 잘라, 예전에 끝난 건이 최근으로 섞임
2. 같은 `lot_no`라도 `product_code`가 다르면 다른 로트인데 번호만으로 조인
3. 재시험 합격(`PASS_AFTER_RETEST`)을 실패로 넣어 실패율 과대
4. "화면 좀 고쳐 줘"처럼 짧은 지시를 AI가 알아서 해석해, 요청하지 않은 것까지 바꿈

## 2. 핵심 해결 방식 — IntentSpec 코어 루프

**애매한 질문 → 4축 구체화 → 🔒 의도 잠금 → (분석이면) SQL + 결정론적 점검**

1. **4축 구체화** — 도메인이 바뀌어도 같은 네 가지를 먼저 고정한다.
   🎯 **목적**(뭐가 나오면 성공인가) / 🧱 **제약**(시간·돈·규칙 중 무엇을 지키나) / ⚖️ **기준**(답이 갈릴 때 무엇을 믿나) / 🧭 **다음**(정한 뒤 바로 무엇을 하나)
2. **추천은 제시하되 자동 선택하지 않는다.** 추천 칩은 보이기만 하고, 사용자가 눌러야 선택된다. 여러 개를 골라도 된다.
3. **🔒 의도 잠금** — 네 축을 모두 고르기 전에는 확정 버튼이 열리지 않는다(`아직 확정 불가 · N개 남음`). 확정하면 고른 기준을 모은 **확정 카드**가 만들어지고, 이 카드가 AI·동료에게 넘기는 지시문이 된다.
4. **잠금 전 실행·반출 금지** — 확정 전에는 SQL·요약을 보여 주지 않고 내보내기를 차단한다(`내보내기 차단`). 기준을 바꾸면 확정·SQL·점검이 무효가 되어 다시 잠가야 한다.
5. **데이터 분석이면 SQL + 결정론적 감사** — 잠긴 기준으로 확정 SQL을 만들고, 확정 전 의심 SQL과 나란히 비교한다. 결과 CSV는 정해진 규칙으로 감사한다: 기간 기준(적재일 혼입), 묶는 키(제품코드 누락), 측정 정의(재시험 합격 혼입), 중복(같은 로트 두 번), 누락(분모 빠짐). 감사는 **의도 드리프트 점수(0~100)** 와 근거 행을 함께 돌려주고, 점검을 통과하기 전에는 내보낼 수 없다.
6. **콘솔 에이전트의 안전장치** — 대화 중 "자기 마음대로", "의도 못 읽음", "합의 전에 고치지 마"가 감지되면 콘솔 작업을 멈추고 「AI한테 원하는 거 말하기」 케이스로 보낸다.

## 3. 구현 범위

**랜딩 6개 케이스** — 일상에서 바로 알아보는 상황으로 진입한다.

| 카테고리 | 케이스 | 경로 |
| --- | --- | --- |
| 사람 ↔ AI | AI한테 원하는 거 말하기 | `/clarify/collab` |
| 사람 ↔ AI | 일상 질문 | `/clarify/everyday` |
| 조사 · 분석 | 연구 · 조사 | `/clarify/research` |
| 조사 · 분석 | 데이터 정의 맞추기 | `/console/semantic?tab=analyze&case=quality` |
| 운영 · 연동 | 시스템 연동 | `/console/semantic?tab=analyze&case=sap` |
| 운영 · 연동 | 재무 · 세무 대조 | `/console/semantic?tab=analyze&case=vat` |

**Clarify 워크스페이스** (`/clarify/*`) — 원문을 넣으면 4축 선택지 카드가 나오고, 선택 → 확정 → 카드 복사까지 한 화면에서 끝난다. 목적·제약·기준·다음이 축별 색으로 구분된다.

**IntentSpec 콘솔** (`/console/semantic`) — Analyze · Catalog · Ontology · Metrics · Lineage 5개 탭.
- **Analyze**: 질문 + 용어 정의서 + 스키마 → 애매한 기준 목록(날짜 기준·식별 범위·용어 충돌·집계 방식·정의 부족) → 기준 확정 → 확정 SQL·점검 항목 → 결과 CSV 감사 → 내보내기
- **Catalog**: 테이블·컬럼 확인, 선택 테이블을 분석 스키마로 반영
- **Ontology**: 의도 → 용어 → 컬럼 매핑 초안, 확정 전에는 `미확정`
- **Metrics**: 확정된 명세 기준 지표·grain 고정
- **Lineage**: 엔터티 조인 관계 그래프

**내장 시나리오 4종** (전부 가상 데이터): 품질·로트 실패율(기본), SAP RFC/EAI 메타 연동, 부가세 SAP↔홈택스, 급여·원천세. 부가세·급여는 콘솔 안에서 고른다.

## 4. Liner API 활용

| API | 호출 지점 | 역할 |
| --- | --- | --- |
| Model API (`liner-gpt-router`) | `/api/analyze` | 질문·정의서·스키마에서 개념 연결과 애매한 기준 추출 |
| Model API (`liner-gpt-router`) | `/api/confirm` | 사람이 고른 기준을 반영해 SQL·점검 항목·근거 생성 |
| Model API (`liner-gpt-router`) | `/api/audit` | 결과 CSV를 확정 기준과 비교해 의도 드리프트 점수·근거 행 산출 |
| Model API (`liner-gpt-router`) | `/api/clarify` | 원문에서 4축(목적·제약·기준·다음) 선택지 생성 |
| Model API (`liner-gpt-router`) | `/api/console-chat` | 콘솔 에이전트 — 카탈로그·온톨로지·지표·관계 안내와 액션 제안 |
| Scholar Search | `/api/analyze` | 애매한 용어의 학술 근거 보강, 출처 URL은 http(s)만 통과 |

`LINER_API_KEY`가 없거나 인증·호출이 실패하면 **100% 같은 시나리오의 가상 데모 엔진**으로 즉시 대체된다. 그래서 심사·시연 환경에서 네트워크나 크레딧 상태와 무관하게 동일한 흐름을 보여 줄 수 있고, 화면에는 "예제 모드"로 표시된다. 키는 `.env.local`로만 두고 저장소에는 값이 없다(`.env.example`).

## 5. 규정 준수 및 개발 구분

- **가상 데이터 100%** (참가 규정 제5조) — 가상 법인·전표·세금코드·로트/시험/판정·급여 런만 사용한다. 회사 내부 문서, 영업비밀, 고객·개인정보는 쓰지 않았다. 실시스템 호출, 실신고, 실지급 대행은 없다.
- **대회 기간 신규 개발** — 기존 결과물을 발전시킨 부분은 없다. 저장소의 코드 전체를 대회 기간(2026-11-12 ~ 11-25)에 새로 작성했다. 이전에 만든 기획 초안은 아이디어 정리용 문서이며 코드는 포함하지 않는다.

## 6. 확장성 및 기대 효과

**확장성** — "정의가 갈리는 자연어 → 구조화된 실행"이라는 패턴은 도메인을 가리지 않는다. 품질·임상·연구를 넘어 재무(미수금 기준일), 행정(민원 처리 기간), 물류(출하 기준일), 의료(투약 기간)까지 같은 4축·잠금·감사 구조를 그대로 재사용할 수 있다. 콘솔의 Catalog·Ontology·Metrics와 결합하면 기업의 시맨틱 레이어 위에서 동작하고, 잠근 기준 카드는 조직의 표준 정의로 축적된다.

**기대 효과**
- 분석 1건당 기준 대조에 드는 수십 분을 선택 몇 번으로 줄인다
- 틀린 숫자가 회의 자료·신고서로 나가는 일을 실행 전에 막는다
- "왜 이 숫자인가"를 확정 카드와 감사 근거 행으로 남겨 리뷰와 감사가 가능하다
- AI에게 일을 맡기는 순간의 불안("알아서 하지 마")을 제품의 기본 동작으로 해소한다
